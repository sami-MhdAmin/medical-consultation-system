# 🏥 Medical Consultation System
A full-stack application built with Flutter and Spring Boot that enables remote medical consultations between doctors and patients. The platform supports real-time chat, medical record management, and secure user authentication.

# ⚙️ Features
* Patient registration, login, and profile management

* Browse doctors by specialization and request consultations

* Real-time doctor-patient chat using WebSockets and STOMP

* Each chat is tied to a consultation session; doctors can open/close chat rooms

* JWT-based authentication and role-based access control

* API documentation using Swagger

* Cloudinary integration for secure document and image uploads

* Pagination and performance optimizations to handle large datasets

# 🛠️ Tech Stack
* Mobile Application: Flutter -> https://github.com/sami-MhdAmin/Flutter-Medical-Consultation

* Backend: Spring Boot

* Authentication: JWT

* Real-time Communication: WebSocket, STOMP

* Database: MySQL

* Media Storage: Cloudinary

* API Testing/Docs: Swagger
